# MyNotes

A Flutter Application which is primarily focused for the WEB and ANDROID platforms. The same code may or may not work on iOS, macOS, windows or other platforms. Complete functinality is not guarenteed for other platforms and NO BUG FIX REQUESTS will be entertained for the platforms NOT SUPPORTED.

## Features

The following are the features available on the application:

- Cloud Authentication
- Forgot password feature
- Notes can be created on the cloud.
- Notes can be deleted.
- Notes can be shared.
- Protected by Firebase App Check
- Android version supports in-app-updates
- Users can fill a feedback form and provide suggestions
- Notes are sorted based on last opened time
- Android Notifications can be send via Firebase Cloud Messaging
- Each note has a checkbox which can be "checked" or "unchecked"
- Each note has a "Heading" and the "Notes Body"
